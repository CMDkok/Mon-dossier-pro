2. Remplis tes informations

Attention : la norme locale de ce modèle exclut la photo. Si tu la mets quand même, le CV sortira avec photo, mais ce ne sera pas conforme à la norme du pays. Pour un CV avec photo, choisis un modèle Francophone (ou Allemand).
Traduction : sur ce modèle, le bouton traduit ton texte français vers la langue du modèle grâce au service public gratuit MyMemory, quand la connexion le permet, puis le reformule de façon professionnelle. Ton texte est envoyé à ce service externe gratuit pour la traduction.
Création et aperçu gratuits. Pour recevoir le PDF final (impression ou envoi par email) : 1 000 F, par Flooz ou TMoney, vérifié à la main avant envoi. Version d'essai gratuite, sans verrouillage technique.

3. Aperçu

Vérifie ton CV ci-dessous avant de le télécharger.

Sur iPhone, dans Safari : touche le bouton, puis dans le menu Partager choisis Imprimer, puis Enregistrer dans Fichiers / Enregistrer au format PDF. Vérifie ensuite le fichier dans Fichiers / Téléchargements.

WhatsApp ne peut pas joindre un fichier tout seul : il envoie seulement un texte. Télécharge d'abord ton PDF, puis dans WhatsApp touche + puis Document et joins le PDF téléchargé.
